# DSBench

Primary benchmark for DataScientistOS.

Official repository:

https://github.com/LiqiangJing/DSBench

Target week-one subset:

- 30 analysis tasks
- 10 modeling tasks
- 40 tasks total

Important:

- reference answers remain evaluator-only
- benchmark data must be handled according to the benchmark license
- task IDs are selected in `selected_tasks.json` (30 analysis + 10 modeling), copied
  verbatim from `external/dsbench/data_analysis/data.json` and
  `external/dsbench/data_modeling/data.json`
- the raw competition/Kaggle data itself is not bundled here; download it per
  `external/dsbench/data_analysis/readme.md` and `data_modeling/readme.md` before
  running these tasks
